# Chikmagalur Filter Coffee — Vercel deployment

IMPORTANT: Upload the CONTENTS of this folder directly into the ROOT of your GitHub repository.
Do not upload this whole folder as a nested folder.

Correct GitHub structure:
- index.html
- admin.html
- admin/
- assets/
- style.css
- script.js
- admin.css
- admin.js
- vercel.json

After pushing to GitHub, Vercel should use the repository root as its Root Directory.

URLs:
- /                 -> storefront
- /admin            -> owner admin panel
- /admin.html       -> owner admin panel
